### Performance

- [GT-DPDK-24.11-0754] Optimize virtio statistics counter update performance, reduce branching and sort packet size comparisons by typical traffic probability. (commits: e9dac45)

- [GT-DPDK-24.11-0758] Optimize the scheduler subtree search and change the search direction from downward to upward to avoid traversing irrelevant branches and improve processing speed. (commits: 4376d9f)
- [GT-DPDK-24.11-0759] Optimize thread creation performance by using pthread_attr_setaffinity_np to set CPU affinity before creating threads to avoid synchronization waits. (commits: 64f2788)
