## Important Changes

### Architecture-related Changes

- [GT-OPENSSL-3.4.0-0010] The CMP client newly supports requesting CRL updates through genm messages, and receiving CRLs through genp messages, and adds corresponding command line options. (Architecture-related: CMP protocol) (PRs: #23768, #24409; commits: 40a200f, 6a3579e, ee28152)
- [GT-OPENSSL-3.4.0-0013] Added integrity-only cipher suite support to TLS v1.3, including adding ssl_cipher_get_evp_md_mac() API, extending the record layer to support MAC-only operations, adding build options and test vectors. (Architecture-related: TLS 1.3 integrity suite) (PRs: #22903; commits: b6a5e80)
- [GT-OPENSSL-3.4.0-0018] Enable support for POSIX context functions on FreeBSD for compatibility with asynchronous operations. (Architecture-related: Platform compatibility) (PRs: #23885; commits: 9aad59c)
- [GT-OPENSSL-3.4.0-0019] Added a function for QUIC stream reception to determine whether there is data waiting to be read. (Architecture-related: public API) (PRs: #24040; commits: 26dd6ba)
- [GT-OPENSSL-3.4.0-0020] Added CPU capability detection and CPUINFO printing support on the RISC-V platform, so that OpenSSL can also output CPU capability information on the RISC-V architecture. (Architecture-related: platform compatibility) (PRs: #24172; commits: 66ad636, c1bf576)
- [GT-OPENSSL-3.4.0-0021] Make the conf_diagnostics configuration also apply to SSL configuration errors. (Architecture-related: Configuration diagnostics behavior) (PRs: #24275; commits: 21819f7, 3e191f4, a0d37e2, af0561d)
