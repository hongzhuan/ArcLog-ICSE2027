## Important Changes

### Application Layer (CLI Tools)

- [GT-OPENSSL-3.5.0-0032] Added the CMS_NO_SIGNING_TIME flag to allow the creation of CMS SignedData signatures without the signature time attribute, and added the -no_signing_time option to the cms command line tool. (Architecture-related: public API) (PRs: #15777, #15783; commits: 34ea176)
