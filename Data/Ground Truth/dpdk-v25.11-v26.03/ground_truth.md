# Ground Truth for dpdk-v25.11-v26.03

## Important Changes

### Application Layer

- [GT-DPDK-26.03-0052] The testpmd txonly multi-flow mode adds a configurable number of flows, a new --txonly-flows parameter and a set txonly-flows command. (Architecture-related: public API) (commits: 8d16bc5)
- [GT-DPDK-26.03-0060] testpmd's --rxq-share parameter now dynamically allocates Rx queue sharing groups. (Architecture-related: configuration behavior) (commits: 1a9c36e, bc63569)
- [GT-DPDK-26.03-0134] Change the upper limit of the number of worker threads from a fixed value of 128 to RTE_MAX_LCORE to fix buffer overflow on high-core platforms. (Architecture-related: Platform compatibility) (commits: be237f6)
- [GT-DPDK-26.03-0398] Optimized the memory pool object acquisition function, removed compile-time constant checks, and adjusted the cache update order to improve performance. (Architecture-related: public API) (commits: 80386cc)
- [GT-DPDK-26.03-0400] Optimized the __rte_pktmbuf_free_direct function, reducing one memory storage operation and improving performance. (Architecture-related: public API) (commits: c53d28c)
- [GT-DPDK-26.03-0418] Added bounds checks and loop counters to descriptor chain traversal of the vhost control queue to prevent malicious guests from causing memory corruption or infinite loops. (Architecture-related: vhost core module) (commits: 6ec1778)
- [GT-DPDK-26.03-0420] Disable empty BPF programs and fix the problem of buffer out-of-bounds reading caused by the acceptance of no-instruction programs and the lack of EXIT instructions. (Architecture-related: BPF core module) (commits: cee21cc)
