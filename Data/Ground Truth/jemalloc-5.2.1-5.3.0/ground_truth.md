# Ground Truth for jemalloc-5.2.1-5.3.0

## Important Changes

### Architecture-related Changes

- [GT-JEMALLOC-5.3.0-0094] Refactor the core profiling code into two logical parts: prof_data.c is responsible for internal data structure management and dumping, prof.c is responsible for mutex locks and external API. (Architecture-related: separation of module responsibilities) (PRs: #1575; commits: 07ce243)
- [GT-JEMALLOC-5.3.0-0096] Removed extent split related functions' dependence on arena and used edata_cache and ehooks parameters instead. (Architecture-related: interface changes) (PRs: #1705; commits: 56cc56b)
- [GT-JEMALLOC-5.3.0-0097] Change the header file name of the extent module from extent2 to extent, and update related references. (Architecture-related: public API changes) (PRs: #1705; commits: e210ccc)
- [GT-JEMALLOC-5.3.0-0099] Move page size index type and size class index type from jemalloc_internal_types.h to sz.h, and update related header file references. (Architecture-related: public API) (PRs: #1770; commits: 34b7165)
- [GT-JEMALLOC-5.3.0-0105] Remove the cache index randomization logic from the extent module and simplify the extent interface so that it only focuses on page-level allocation. (Architecture-related: public API) (PRs: #1804; commits: 585f925)
- [GT-JEMALLOC-5.3.0-0106] Migrate the arena_decay_extent function to the extent module. (Architecture-related: public API) (PRs: #1804; commits: 22a0a7b)
- [GT-JEMALLOC-5.3.0-0108] Migrate caching, statistics and recycling logic related to page allocation from arena to pa_shard module, and remove arena's direct knowledge of extent. (Architecture-related: Module responsibilities: Migrate page allocation to pa_shard) (PRs: #1804; commits: eba35e2)
- [GT-JEMALLOC-5.3.0-0109] Migrate arena's decay time acquisition function to the pa module, and update related calls to use the new pa_shard interface. (Architecture-related: Module responsibility: Migrate decay time acquisition to pa) (PRs: #1804; commits: e77f47a)
- [GT-JEMALLOC-5.3.0-0110] Migrate slab allocation related code to the newly extracted page allocation (pa) module, use edata instead of extent type, and uniformly allocate and recycle through the pa_shard interface. (Architecture-related: Module responsibility: slab allocation is migrated to pa) (PRs: #1804; commits: 7be3dea)
- [GT-JEMALLOC-5.3.0-0111] Move extent statistics to the PA module, and remove atomic operations and replace them with direct assignment. (Architecture-related: Module responsibility: Migrate extent statistics to PA) (PRs: #1804; commits: f6bfa3d)
- [GT-JEMALLOC-5.3.0-0112] Move the in_hook field and tsd_link field in tcache into the TSD structure, and update the access methods of related functions. (Architecture-related: Module responsibility: Move the tcache field into TSD) (PRs: #1813; commits: 40e7aed)
- [GT-JEMALLOC-5.3.0-0113] Change the cache filling function of arena from directly relying on tcache to being based on cache_bins, thereby decoupling the internal implementation of arena and tcache. (Architecture-related: Module responsibility: Decoupling arena and tcache) (PRs: #1813; commits: 7099c66)
- [GT-JEMALLOC-5.3.0-0137] Rename guard-related names to san to lay the foundation for subsequent sanitizer work. (Architecture-related: public API rename) (PRs: #2151; commits: 62f9c54)
- [GT-JEMALLOC-5.3.0-0150] Added a new mallctl interface for dumping the latest N performance analysis records, and added corresponding unit tests. (Architecture-related: mallctl interface) (PRs: #1759, #1760, #1808; commits: 68e8ddc, 9d2cc3b, c4e9ea8)
- [GT-JEMALLOC-5.3.0-0152] Added the edata_cache_small_t type to allocate the synchronization overhead of edata_cache access; adjusted the naming and initialization logic of related functions. (Architecture-related: edata_cache_small_t type) (PRs: #1782; commits: 734109d, 99b1291)
- [GT-JEMALLOC-5.3.0-0160] Added malloc_conf_2_conf_harder configuration source, allowing users to override the parameters of the configuration system settings. (Architecture-related: configuration override) (PRs: #1802; commits: d936b46)
- [GT-JEMALLOC-5.3.0-0170] Added output space verification before mallctl re-operation, implemented by adding a new search function and adjusting the control interface. (Architecture-related: public API) (PRs: #1885; commits: fb347dc)
- [GT-JEMALLOC-5.3.0-0171] Added range iteration support for flat bitmap, and added corresponding unit tests. (Architecture-related: public API) (PRs: #1888; commits: ddb8dc4)
- [GT-JEMALLOC-5.3.0-0172] Expand the control interface, add ctl_mibnametomib and ctl_bymibname functions, support control query through partial names and partial MIBs. (Architecture-related: public API) (PRs: #1908; commits: 006dd04, 4557c0a, 6ab181d)
- [GT-JEMALLOC-5.3.0-0174] The ctl_lookup function now supports searching from any node, and is no longer forced to start from the root node. (Architecture-related: public API) (PRs: #1908; commits: 3a627b9, 91e006c)
- [GT-JEMALLOC-5.3.0-0175] The range parameter of PRNG is now allowed to be 1, and the related function interface has been simplified. (Architecture-related: public API) (PRs: #1909; commits: 0513047, 2a6ba12)
- [GT-JEMALLOC-5.3.0-0176] The profiling information now records the size of each allocation request. (Architecture-related: public API) (PRs: #1914; commits: afa489c)
- [GT-JEMALLOC-5.3.0-0183] Added --with-lg-slab-maxregs configuration option, allowing customization of the maximum number of regions in slab. (Architecture-related: build and installation methods) (PRs: #1930; commits: 1541ffc)
- [GT-JEMALLOC-5.3.0-0184] The edata structure adds an age field, provides get and set functions, and adds age-based comparison logic and corresponding heap types. (Architecture-related: public API) (PRs: #1942; commits: 634ec6f)
- [GT-JEMALLOC-5.3.0-0186] The slab_sizes configuration item has a new default option, allowing it to be reset to the default value. (Architecture-related: public API) (PRs: #1948; commits: b971f7c)
- [GT-JEMALLOC-5.3.0-0210] Added summarize/filter function for red-black trees, supporting tracking additional information in nodes to filter searches. (Architecture-related: public API) (PRs: #2042; commits: 5417938)
- [GT-JEMALLOC-5.3.0-0247] In mallctl, when the output buffer space is insufficient, the output length pointer is updated to reflect the actual copied data length. (Architecture-related: public API behavior) (PRs: #1885; commits: f5fb4e5)
- [GT-JEMALLOC-5.3.0-0249] Fix the behavioral consistency of ctl_nametomib in the reverse case to ensure that it does not fail when the mib array length is larger than the name. (Architecture-related: public API: ctl_nametomib behavioral consistency) (PRs: #1908; commits: f2e1a5b)
- [GT-JEMALLOC-5.3.0-0255] Fixed an issue where malloc_conf configuration string was not triggering abort under abort_conf:true when it ended with a key, ended with a comma or was malformed. (Architecture-related: configuration behavior) (PRs: #2171; commits: af6ee27)
- [GT-JEMALLOC-5.3.0-0310] Added conditional compilation protection to the C++ aligned allocation and deallocation API, which is only enabled when supporting the C++17 aligned new feature, and refactored the C++ API order, adding the alignedSizedDeleteImpl inline function to eliminate compilation warnings. (Architecture-related: public API) (PRs: #1692, #1787; commits: 5c47a30, b30a5c2)
- [GT-JEMALLOC-5.3.0-0314] Rename the core type extent_t to edata_t to resolve the naming conflict. (Architecture-related: Core type renaming) (PRs: #1705; commits: a7862df)
- [GT-JEMALLOC-5.3.0-0319] Removed the extent merging function's dependence on arena, and instead passed in edata_cache through parameters to decouple the association between the extent module and arena. (Architecture-related: module decoupling) (PRs: #1705; commits: 372042a, 48ec5d4)
- [GT-JEMALLOC-5.3.0-0328] Removed the prof_lookup_global function, replaced the b0get call in prof_boot2 with the passed base parameter, and renamed prof_dump_seq_mtx to prof_dump_filename_mtx. (Architecture-related: public API: removed function) (PRs: #1623, #1770; commits: 242af43, 29436fa)
- [GT-JEMALLOC-5.3.0-0330] Remove the memory filling (junking) logic from the allocation and release path of tcache and arena, and change it to be processed at a higher level to simplify the internal logic and keep the fast path unaffected. (Architecture-related: External behavior: Memory filling logic movement) (PRs: #1784; commits: 79f1ee2)
- [GT-JEMALLOC-5.3.0-0331] The interface of the cache_bin module is simplified, and the functions that require index and info array are changed to only accept a single info pointer, and the caller directly passes in the corresponding info. (Architecture-related: public API: interface simplification) (PRs: #1784; commits: e1dcc55)
- [GT-JEMALLOC-5.3.0-0335] Moved the attribute modification operations of edata (szind, size, szind, sn, zeroed and state initialization) from the emap module back to the extent module, and adjusted the module responsibility boundary. (Architecture-related: Module responsibility adjustment) (PRs: #1804; commits: 0c96a2f, 883ab32, dfef0df)
- [GT-JEMALLOC-5.3.0-0344] Thread event processing is reconstructed, and waiting time calculation and delayed waiting time are extracted into independent functions, which are defined by each module to eliminate inter-module dependencies. (Architecture-related: cross-module interface reconstruction) (PRs: #1796; commits: 733ae91, abd4674)
- [GT-JEMALLOC-5.3.0-0346] The caller is required to manually clear edata_t on the stack before using it to avoid undefined behavior; at the same time, the parameters of edata_init are modified and the edata_hugeified_set function is removed. (Architecture-related: public API) (PRs: #1848; commits: eda9c28)
- [GT-JEMALLOC-5.3.0-0379] Added assert_* macros and p_test_failed function to the test framework, which supports aborting the test immediately when the assertion fails, and has been applied to some test files. (Architecture-related: public API) (PRs: #1760; commits: 21dfa43, a88d22e, fa61579)
- [GT-JEMALLOC-5.3.0-0381] Replaced the dump file opening function in the test with the new interception function, and adjusted the relevant test assertions accordingly. (Architecture-related: public API) (PRs: #1794; commits: f307b25)
