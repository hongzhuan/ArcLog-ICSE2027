### Core Data Structures

- [GT-DPDK-25.11-0025] Add trace points for each operation type of bbdev, and add experimental API rte_bbdev_ops_trace to record input parameters of different operation types. (Architecture-related: public API) (commits: 62fc205)

### Performance

- [GT-DPDK-25.11-0640] Optimized the acquire and release operations of the DPAA memory pool, using the new BMan API and supporting burst release, improving release performance by about 90%. (commits: 637bde7)
- [GT-DPDK-25.11-0642] Renamed and optimized the mbuf seed function for the Ark NIC Rx queue, adopting a 4K aligned buffer allocation strategy to reduce PCIe requests, and trying to allocate smaller blocks when memory is exhausted. (commits: af94cac)
- [GT-DPDK-25.11-0643] Optimized the ENA network card Tx descriptor field setting method, replacing the operation of erasing first and then setting by direct assignment to improve performance. (commits: fa2f757)
- [GT-DPDK-25.11-0644] Removed the redundant clearing operation of the Tx descriptor in the ENA network card LLQ scenario and utilized the existing bounce buffer clearing mechanism. (commits: cb856ed)
- [GT-DPDK-25.11-0645] Optimized the ENETC4 data path, separated cache coherence operations into separate RX/TX functions, reduced memory accesses, and added checksum offloading and fragmented packet type parsing support. (commits: 72f491f)
- [GT-DPDK-25.11-0646] Fixed performance issues with the Thor2 TruFlow memory manager: moving full blocks to the end of the list, making sure searches stop correctly when encountering the first full block. (commits: d4b1493)
- [GT-DPDK-25.11-0647] For the E830 network card, when the number of queues is less than 64, the global RSS LUT is used to improve performance. (commits: 193a11f)
