# Ground Truth for openssl-3.5.0-3.6.0

## Important Changes

### Architecture-related Changes

- [GT-OPENSSL-3.6.0-0017] Introduce a thunk mechanism to the OPENSSL_sk interface, allow setting a custom release function, and call this function in OPENSSL_sk_pop_free to avoid UBSan warnings. (Architecture-related: public API) (PRs: #22896, #27071; commits: 21b170d)
- [GT-OPENSSL-3.6.0-0018] Reconstruct the parameter auxiliary code and add the OSSL_PARAM_set_octet_string_or_ptr function. (Architecture-related: public API) (PRs: #27221; commits: ac01b9a)
- [GT-OPENSSL-3.6.0-0030] Added a new array memory allocation routine to automatically perform integer overflow checking to make allocation semantics clearer. (Architecture-related: public API) (PRs: #28059; commits: 351caeb, 354e78c, 5398d5c, 5fab189, bd1c597, f3a4d05, fa9b7b9)
- [GT-OPENSSL-3.6.0-0086] Fix default private key DER output format to PKCS#8, and extend -traditional option to support DER output. (Architecture-related: CLI behavior) (PRs: #21708, #27273; commits: f492649)
- [GT-OPENSSL-3.6.0-0110] Removed the deprecated _strlen31 function with potentially serious side effects and its strlen macro redefinition on Win64 platforms. (Architecture-related: Platform compatibility) (PRs: #27761, #27763; commits: b0d363a)
- [GT-OPENSSL-3.6.0-0112] Allows reuse of thread-local storage keys in threadless configurations, breaking the hard limit of 256 LIB_CTX values. (Architecture-related: Platform compatibility) (PRs: #27757, #27775; commits: b6d01d1)
- [GT-OPENSSL-3.6.0-0137] Correct the synthesis logic of the pre-release version identifier in the OPENSSL_VERSION_NUMBER macro to ensure that 0xfL is correctly generated when there is no pre-release version. (Architecture-related: version and compatibility) (PRs: #28230; commits: ba2c314)
- [GT-OPENSSL-3.6.0-0299] Add conditional compilation to FIPS-specific parameters in multiple KDF and encryption algorithm implementations, making them available only in FIPS mode to enhance FIPS compliance. (Architecture-related: FIPS compliance) (PRs: #28163, #28243; commits: 004077b, 1aae0a4, 1b71051, 226b5a5, 2d1280e, 2f205fc, 3473f69, 40dd58e, 472ead8, 4e1eaa1, 60f8ff1, 88d544c, a9d7e69, b27f840, b411ef0, b830eba, ba2b292, c098acb, ecc3491, f9bf224, fc7a72d, fd3a6a4)
- [GT-OPENSSL-3.6.0-0463] Change parameter splitting to support spaces within quotes to avoid command injection, and use custom quotes to construct commands on Windows. (Architecture-related: platform compatibility) (PRs: #27432; commits: 287bbb2)
- [GT-OPENSSL-3.6.0-0483] Updated INSTALL.md to explain that LMS supports disabling by default and needs to be explicitly enabled through the enable-lms option. (Architecture-related: build and installation methods) (PRs: #27885; commits: 17a1637, 495f5fa)
- [GT-OPENSSL-3.6.0-0509] Fixed multiple build issues on UEFI platforms, including disabling the OSSL_PARAM_REAL branch, adding stddef.h header file inclusion, and adding a new RIO_POLL_METHOD_NONE method. (Architecture-related: Platform compatibility) (PRs: #27284; commits: 44e9c5a, 57f9447, 7e53ffa)
- [GT-OPENSSL-3.6.0-0510] Added nightly testing task for riscv64 architecture in CI workflow. (Architecture-related: platform compatibility) (PRs: #27240; commits: 3513a83)
- [GT-OPENSSL-3.6.0-0511] Fixed build failure on OS X 10.4 Tiger, added PowerPC build configuration and adjusted header files. (Architecture-related: Platform compatibility) (PRs: #27578; commits: 7eee9d5)
- [GT-OPENSSL-3.6.0-0512] Fixed the build problem of VC-WIN64-CLANGASM-ARM target on Windows ARM64, added the check of _M_ARM64 macro. (Architecture-related: platform compatibility) (PRs: #22949, #27958; commits: c66d976)
- [GT-OPENSSL-3.6.0-0551] Added deprecated macros for OpenSSL 3.6.0. (Architecture-related: public API: deprecated macros) (PRs: #27727; commits: 1bc3191)

### BIO Layer

- [GT-OPENSSL-3.6.0-0131] Fix the processing of negative width parameters in bio_print.c so that it conforms to the printf specification, and negative width is correctly regarded as a left-aligned flag. (Architecture-related: external behavior) (PRs: #28177; commits: 7eb18e7)
- [GT-OPENSSL-3.6.0-0132] Fixed the problem of incorrectly adding a prefix when the value is zero in octal and hexadecimal formatting. (Architecture-related: external behavior) (PRs: #28177; commits: 0f6e826)
- [GT-OPENSSL-3.6.0-0135] Fixed the problem of OSSL_DECODER_CTX_new_for_pkey not releasing the write lock in the memory allocation failure path to avoid assertion failure due to repeated locking by the same thread. (Architecture-related: public API) (PRs: #28216; commits: c052725)
- [GT-OPENSSL-3.6.0-0143] Fix the problem of BIO_snprintf not terminating output with \0 in the wrong path, and adjust related tests to verify this behavior. (Architecture-related: public API) (PRs: #28177; commits: 7777db8)
